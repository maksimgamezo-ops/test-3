# Инвентаризация ассетов

| Материал | Происхождение | Условия / статус |
|---|---|---|
| `scripts/create_architecture.py` | Авторская процедурная архитектура, создана в этой задаче; фиксированный seed 193875217 | Без заимствованных моделей и текстур. Код и результат предоставлены в составе проекта; согласование прав в рамках договора с владельцем сайта остаётся его ответственностью |
| `assets/architecture.blend` | Blender 4.3.2, результат скрипта | Исходник для редактирования. Названия групп соответствуют стадиям анимации |
| `public/models/architecture.glb` | Экспорт из того же Blender-проекта | Единая модель, PBR, шесть объединённых групп; около 1.2 MB. Без внешних загрузок, Draco-декодера и удалённых HDRI. Дополнительное mesh-сжатие не применялось: размер уже ограничен |
| `public/images/architecture-*.png` | Cycles CPU, те же геометрия и материалы | Исходные рендеры desktop 1920×1200 и mobile 1000×1200; desktop PNG используется для Open Graph |
| `public/images/architecture-*.webp` | Преобразование исходных рендеров Pillow, quality 91 | Адаптивные постеры и резерв WebGL, отдельный мобильный ракурс |
| `public/fonts/NotoSans-*.ttf` | Системный пакет fonts-noto-core, проект Noto | SIL Open Font License; полный текст и сведения — `public/fonts/LICENSE.txt` |
| `public/fonts/symbols.woff` | Подмножество DejaVu Sans из fonts-dejavu-core | Лицензия Bitstream Vera/DejaVu, `public/fonts/LICENSE-symbols.txt`. Подмножество стрелок и символов интерфейса; собственное имя шрифта |
| Бренд, телефоны, адрес, УНП, почта | Пользовательское техническое задание | Требуют подтверждения компанией до запуска |
| `large/*.jpg`, `large/*.bat` | Предсуществующие материалы репозитория | Не использованы в сайте, права не установлены, файлы не изменялись |
| `docs/previews/` | Браузерные снимки этой реализации | Демонстрация интерфейса; не фотографии реализованных объектов |

Модель — концепт, а не реальный объект BAUPLANINVEST. Визуальная планка фотореализма уровня Apple не заявляется достигнутой. Крупный план 4K требует отдельного рендера большего разрешения и дополнительной художественной проработки. Не использовать материалы Apple или неподтверждённые фотографии проектов.
