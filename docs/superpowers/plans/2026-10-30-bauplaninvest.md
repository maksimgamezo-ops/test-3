# BAUPLANINVEST Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Создать русскоязычный сайт девелопера с авторской архитектурой, управляемой 15-секундной анимацией и всеми маршрутами из ТЗ.

**Architecture:** Серверные страницы Next.js содержат весь основной текст и контакты. Изолированный клиентский компонент загружает авторский GLB и воспроизводит детерминированную последовательность сборки; статичный рендер обеспечивает независимый от WebGL первый экран.

**Tech Stack:** Next.js App Router, TypeScript, React Three Fiber/Three.js, Blender 4.3, Playwright, Node.js 24.

**Spec:** docs/superpowers/specs/2026-10-30-bauplaninvest-design.md

## Global Constraints
- Авторская концептуальная архитектурная модель, явно обозначенная как концептуальная.
- Не выдумывать проекты, достижения, сроки, гарантии, услуги и домен.
- Не изменять существующие JPEG и BAT.
- Прокрутка страницы остаётся обычной; prefers-reduced-motion исключает автоматическое движение.
- Контакты в единой конфигурации; формы без реальной доставки нет.
- Не публиковать сайт без отдельного поручения.

## Review Focus
- Отказ WebGL: текст, контакты и качественный рендер остаются доступными — задача 2.
- Перемотка назад и повтор: все группы возвращаются к правильному состоянию — задача 2.
- Клавиатура и мобильное меню: Escape закрывает, фокус возвращается — задача 3.
- Ограниченная анимация и узкий экран: нет автоматического движения и горизонтального переполнения — задача 4.
- Отсутствующий домен и доставка: нет фиктивных canonical и успешной отправки — задача 4.
